# Xunadu（`xanadu_opt_v1`）调参经验

## 核心思想
Xunadu 基于历史转移边做 EWMA 预测，再按最可能后继路径进行预热。优化版相较原版允许后续执行阶段继续触发计划，因此覆盖率更高，但也更容易在路径分叉时产生误预热。

## 关键参数与经验
- `xanadu_depth`：控制递归预热深度。
  经验：深度越大，`prewarm_cost` 越高，若上下文模式不稳定，利用率可能不升反降。
- `xanadu_ewma_alpha`：历史边概率更新速度。
  经验：`alpha` 大时响应快但噪声大，小时稳定但跟踪慢。对漂移明显的流量，建议中等值。
- `sync_period_sec`（复用全局）：
  经验：周期过长会错过突发，周期过短会产生频繁重算与重复预热。

## 建议调参顺序
1. 固定 `depth=1`，先找合适 `ewma_alpha`。
2. 在 `alpha` 稳定后再考虑深度提升。
3. 若出现“容器数很低但冷启动率高”，优先缩短周期或提高 `alpha`，不要先盲目加深度。
