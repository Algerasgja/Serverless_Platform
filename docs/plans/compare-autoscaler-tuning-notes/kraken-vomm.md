# Kraken（`kraken_vomm_v1`）调参经验

## 核心思想
Kraken 基于马尔可夫转移概率估计后续节点需求，并叠加连接性/公共性权重调整扩容数。它比纯路径预测更结构驱动，优点是覆盖广，缺点是若拓扑分叉多，容易把预算分散到低收益节点。

## 关键参数与经验
- `kraken_misallocation_ratio`：
  经验：该参数用于模拟/控制预算错配，数值越大通常越不利于利用率。
- 周期和窗口（沿用 ConScale 口径）：
  经验：窗口过宽会导致“结构上可达但实际很少触发”的节点被长期预热。
- 权重修正（实现内部）：
  经验：连接性和公共性权重使中枢节点更容易拿到预算，适合链路复用高的 DAG。

## 建议调参顺序
1. 先把错配参数压低，确认基线可用。
2. 再按负载档位调窗口，避免低负载时过度预热。
3. 若 `prewarm_cost` 高而 `prewarm_utilization` 不升，优先收紧可达范围，而不是增加总预算。
