# 扩缩容方法设计思想说明（独立文档）

## 1. 文档目的
本文档独立于 `docs/plans/compare-experiment-design.md`，用于集中说明当前对比实验中各扩缩容方法的核心设计思想、决策依据和能力边界，便于论文写作时直接引用“方法机制描述”部分。

## 2. 当前方法清单（对比脚本口径）

- `Oracle`：`oracle_future_v1`

## 3. 各方法主体思想

### 3.1 ConScale（`hpwp_v1`）
ConScale 的核心思想是“前缀上下文感知 + 分层概率回退 + 紧迫窗口聚合”。它不是只看当前函数节点，而是把请求已执行前缀当作状态，用层次化条件概率去估计后续最可能路径，再将多个活跃请求的前缀需求在函数级聚合为期望容器数。为避免过度预热，ConScale 只对规划窗口内且来不及冷启动覆盖的函数进行优先预热，从而在冷启动率与资源成本之间做动态折中。

### 3.2 Xunadu（`xanadu_opt_v1`）
Xunadu 的主体思想是“基于历史转移的轻量路径预测 + 固定周期对齐扩容”。它通过边转移的指数加权统计持续更新后继偏好，在每次步骤触发时递归预测后续最可能分支，并把请求-函数对映射为函数级预热需求。优化版支持请求在偏离后续又回到高概率链路时重新参与扩容计划，因此比严格一次性失效的策略更鲁棒，但本质仍是历史统计驱动，难以显式建模更深层上下文模式。

### 3.3 Kraken（`kraken_vomm_v1`）
Kraken 的设计思想是“马尔可夫转移概率 + 拓扑结构修正”。它先依据当前节点到后续节点的转移概率估计扩容强度，再引入连接性与公共性等结构特征对基础目标进行放缩，使常见且传播性更强的函数优先获得容量。该方法强调“结构统计可解释性”，在拓扑固定、路径分布相对稳定的 DAG 上通常有效，但当上下文漂移较强时，单纯一阶或低阶转移模型会出现后继估计滞后。

### 3.4 DBW（`depth_breadth_v1`）
DBW 的核心思想是“深度受限的广度覆盖预热”。从当前函数出发，在给定时间窗口内对所有可达后继函数执行广度扩容，不使用概率筛选，因此可以提高路径覆盖率并减少漏判风险。该策略本质是保守型前瞻扩容：对短时突发和多分支 DAG 更稳健，但代价是可能在低概率分支上产生额外预热成本。当前实现通过窗口与缩放参数控制扩容强度，以便在覆盖与成本之间调节。

### 3.5 KPA（`kpa_v1`）
KPA 的主体思想是“并发目标驱动的反应式扩容”。它以函数并发负载为核心信号，通过稳定窗口与 panic 窗口分别刻画常态与突发压力，在固定周期上计算目标副本。相比上下文预测型方法，KPA 不尝试预判路径，只在负载已显性上升后做扩容，因此实现简单、行为稳定、工程可落地性高。其主要短板是对突发冷启动的前置抑制能力有限，往往依赖更高冗余来换取低尾延迟。

### 3.6 LASS（`lass_v1`）
LASS 的设计思想是“目标时延反推容量”。它不依赖 CPU/内存利用率，而是根据近期请求到达量与观测处理速度估算为了满足时延目标所需的容器规模，再在周期上对齐到期望副本。该方法直接面向 SLA 指标，解释性强，适合业务关注“时延约束是否达标”的场景。但若速度估计短时波动较大，或冷启动影响尚未在速度信号中稳定体现，策略会出现扩容抖动或过度保守，需要窗口和平滑参数配合。

### 3.7 HPTD（`hptd_v1`）
HPTD 的核心思想是“调用温度驱动扩容”。它利用 Hawkes 自激过程把历史调用事件映射为函数温度，并通过温度变化量相对历史波动阈值的超额部分触发扩容。该方案适合处理具有时间相关性的负载序列，能够在请求量尚未完全反映到并发前先感知趋势变化。它的关键在于窗口长度和阈值敏感性控制：阈值过低会频繁误触发，过高则会错失提前扩容时机。

### 3.8 QLAS（`rl_q_v1`）
QLAS 的主体思想是“轻量 Q-learning 在线学习扩容动作”。它将函数的局部运行状态离散化后，通过 `{-1, 0, +1}` 动作集合在吞吐/资源收益口径下迭代更新 Q 值，并用 `epsilon-greedy` 在探索与利用之间切换。策略不主动缩容，`-1` 通过抑制后续扩容意图体现保守性。相对规则法，QLAS 能在同一框架下适配不同负载形态，但需要一定学习过程，早期阶段可能出现探索成本和策略不稳定。

### 3.9 Oracle（`oracle_future_v1`）
Oracle 在对比中作为理想上界基线，其思想是假设系统可提前获知请求真实未来路径，并在函数执行前完成精确预热，使请求执行尽量避开真实冷启动。该方法用于给出“理论最优可达性能”参照，而非工程可部署策略。由于其信息假设超出实际可观测边界，Oracle 的价值在于衡量其他算法距离上界还有多大优化空间，而不是作为现实系统直接采用的扩缩容机制。
